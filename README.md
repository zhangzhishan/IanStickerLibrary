# IanStickerBook sticker library

Remote sticker catalog consumed by the private IanStickerBook iOS app.

- `catalog.json` is the versioned manifest.
- `images/` contains downloadable sticker artwork.
- `replacesDefinitionID` lets a downloaded image replace a built-in sticker definition without changing saved collection data.
- Character artwork is for private, non-commercial family use. Rights remain with the respective owners.

## Artwork sources

- Ultraman: Tsuburaya Productions official hero pages and Ultraman Wiki, as documented in the app repository.
- Zootopia: StickPNG character renders; Nick Wilde from PNGGallery.
- Super Wings: StickPNG, Wallpapers.com, the official Super Wings Spain site, and PNGKit character renders.
- Image-based action variants in `images/poses/` are distinct compositions derived from the corresponding base character artwork. They replace the earlier emoji-badge action treatment.
